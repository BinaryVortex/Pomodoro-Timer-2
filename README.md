# Pomodoro Timer

A simple and effective Pomodoro Timer built using HTML, CSS, and JavaScript. This tool helps you manage your time using the Pomodoro Technique, which involves working in focused intervals (typically 25 minutes) followed by short breaks.

## Features

- **Work Sessions**: 25-minute focused work periods
- **Short Breaks**: 5-minute breaks after every work session
- **Long Breaks**: 15-minute breaks after completing 4 work sessions
- **Session Tracking**: Keeps track of your current session and overall progress
- **Goal Progress**: Displays progress towards completing 4 Pomodoro sessions
- **Controls**: Start, Pause, Stop, and Reset buttons for full control over the timer

## How to Use

1. Click **Start** to begin a 25-minute work session.
2. Work focused until the timer reaches zero.
3. Take a 5-minute break (or 15-minute break after every 4 sessions).
4. Repeat the cycle. The app will automatically transition between work and break periods.
5. Use **Pause** to temporarily stop the timer, **Stop** to end the current session, or **Reset** to restart from the beginning.

## Installation
